Data pipelines

Batch pipelines that pull data from public sources, model it, and check it before anyone queries it.

Crypto Market Data Pipeline

Medallion lakehouse on Databricks

Team project, 2026 Source on GitHub

Loads live and historical market data for the top 20 coins from the CoinGecko API into Delta Lake, and models it into tables a trading dashboard reads.

  • Ingestion retries with exponential backoff and stays inside CoinGecko's rate limit.
  • Loads use Delta MERGE, so re-running a batch doesn't duplicate rows.
  • Silver separates dimensions from facts. Rows that fail quality checks are quarantined instead of dropped, and every run is logged with its status and row counts.
  • Gold adds support and resistance levels, performance metrics and a recommendation score for a Databricks Lakeview dashboard.

Stack: PySpark, Databricks, Delta Lake, Python, CoinGecko API

Interop Mapper

ETL and search for the FHIR health data standard

Solo project, 2026 Source on GitHub

FHIR is the HL7 standard that health systems use to exchange records. Type a field like “date of birth” and Interop Mapper shows where it goes (Patient.birthDate) and how it changed between FHIR R4, R4B and R5, with no internet needed once loaded.

  • A Python ETL pulls the official HL7 packages and loads every element, extension and search parameter into SQLite with full-text search.
  • Version diffs cover added and removed fields, cardinality, type and binding changes, and flag likely renames.
  • Generates example JSON, Python, JavaScript and curl for every resource and field. All examples validate against the independent fhir.resources models.
  • Ships as static files: an installable offline app, or a single HTML file you can email.

Stack: Python, SQLite FTS5, JavaScript, service workers

Vibnex

URL shortener API

Solo project, 2025 Live site Source on GitHub

Paste a long link, pick a short code, and share the short one. Two route handlers do all the work: one creates links, one redirects.

  • The create route validates input, adds https:// when the scheme is missing, and checks the short code is free before inserting.
  • The redirect route does a single lookup by short code and answers with a 302.
  • Moved storage from SQLite to Supabase PostgreSQL so it runs on Vercel's serverless functions.

Stack: Next.js route handlers, Supabase (PostgreSQL), Vercel

FinTrack

Personal finance backend and app

Team project, 2025 Source on GitHub

Tracks spending across several accounts. Upload a bank statement PDF or a receipt, and its transactions are read, categorized and saved.

  • Server actions validate input with Zod, then write the transaction and update the account balance in one Prisma $transaction, so balances can't drift from their rows.
  • Gemini reads uploaded statements and receipts and returns structured transactions, categorized from their descriptions.
  • Bulk delete reverses each transaction's effect on its account inside the same database transaction.
  • Filtered views export to .xlsx. Clerk handles sign-in.

Stack: Next.js server actions, TypeScript, Prisma, PostgreSQL (Supabase), Zod, Gemini API, Clerk
